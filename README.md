# RT LAB — النظام الموحّد

برنامج إدارة معمل التحاليل RT LAB: الحجوزات + النتايج + المخزون + الحسابات في مشروع واحد.

## الملفات

| الملف | الوصف |
|--------|--------|
| `index.html` | الصفحة الرئيسية الموحّدة (نقطة الدخول) |
| `RT_LAB_UNIFIED.html` | نفس الواجهة الموحّدة |
| `RT_LAB_LIS_FULL.html` | برنامج النتايج (LIS) + مخزون + مصروفات + حضور |
| `RT_LAB_BOOKING_FULL.html` | برنامج الحجوزات والكروت والعضويات |

## التشغيل

1. ارفع المجلد كاملاً على **GitHub Pages** أو **Netlify**.
2. افتح `index.html` (أو رابط المستودع على GitHub Pages).
3. من القائمة ادخل لكل قسم (حجز / نتائج / مخزون / …).
